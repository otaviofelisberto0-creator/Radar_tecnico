# Dashboard TEC1 | Operações Técnicas — v21

Evolução incremental e cumulativa da v20, pronta para GitHub Pages e JSON mensal hospedado em GitHub Releases.

## Melhoria visual v21

- Banner principal mais baixo, mantendo integralmente a imagem técnica aprovada e a identidade Operações Técnicas.
- Cabeçalho responsivo com Competência, Última atualização e Dados até totalmente legíveis.
- Indicadores executivos posicionados mais cedo na página.
- Melhor contraste, proporção e leitura em desktop, notebook, tablet e celular.
- Uma única rolagem vertical da página; o menu não cria rolagem vertical interna.
- Página ativa continua sincronizada com o menu.

## Recursos preservados

Todas as 13 páginas da v20, análises, indicadores, gráficos, tabelas, filtros contextuais em cascata, critérios, exportações, CSV→JSON, `manifest.json` e integração com GitHub Release.

## Publicação

Publique `index.html`, `.nojekyll` e `dados/` na raiz. Substitua o marcador da URL no `dados/manifest.json` pelo asset HTTPS da GitHub Release.
